# Exhibition Reference Images

Drop clear, local demo photos into these folders before starting the backend:

- `medicine_bottle/` - the exact vitamin bottle used in the exhibit.
- `stove/` - the exact stove view or interaction zone used in the exhibit.
- `faces/Anya/` - reference photos for Anya, the caretaker.

Use 3-8 well-lit images per target when possible. Keep backgrounds similar to
the exhibition setup for the most deterministic OpenCV matching.
